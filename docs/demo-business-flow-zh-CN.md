## 演示账号

- `demo_manager`：研发经理。
- `demo_general_manager`：综合部经理。
- `demo_vp`：副总经理。
- `demo_presales_north`、`demo_presales_east`、`demo_presales_central`、`demo_presales_south`、`demo_presales_southwest`：五名售前，分别配置负责区域。

造数程序使用不可见随机密码，不输出或保存明文。管理员可在账号管理页面重置任一演示账号密码，再以对应角色登录查看权限范围和审批待办。

## 显式执行

首次执行前应完成备份，然后运行：

```powershell
npm.cmd run seed:demo -- --confirm-demo-data --admin admin
```

命令只在显式确认时写入。完成后再次执行会识别完成标记，不重复创建数据；如果检测到未完成的部分批次，会停止并要求从写入前备份恢复或人工核对，不会自动覆盖或删除记录。
