## 启停

前台启动：

```powershell
npm.cmd start
```

供 Windows 登录自启使用的稳定入口：

```powershell
npm.cmd run start:local-service
```

该入口会先把工作目录固定为项目根目录，再读取本机 `.env`，避免计划任务从其他目录启动时误用数据库或找不到配置。
