# 对客报价单模板 v1

## 来源与用途

- 来源：用户提供的实际对客报价 Word，仅用于提炼版式和字段结构。
- 运行时模板：`quote-template-v1.docx`。
- 原文件中的示例客户、报价人和两份示例附件已移除，不进入系统模板。

## 固定版式

- A4 纵向，保留原页边距、首屏 Logo / 页眉、标题、公司信息和三张主表的位置关系。
- 主文档固定为：客户及报价信息、项目总价、项目费用明细、含税金额大写、交期、付款方式、开户行、账号、报价人信息。
- 公司名称、地址、邮编和公司电话沿用用户提供的报价单口径。

## 运行时填充

- 报价编号、日期、有效期、客户名称、客户联系人、客户电话。
- 项目总价逐行填充：项目 / 型号、单位、数量、未税单价、未税金额、含税金额、备注。
- 项目费用明细逐行填充：项目、子项、单位、数量、未税单价、未税金额、含税金额、备注。
- 原含税合计、优惠金额、最终优惠价及人民币大写。
- 交期、付款方式、开户行、账号、报价人姓名 / 电话 / 邮箱。

## 附件规则

- 附件按报价提交时的不可变快照顺序编号，另起一页并入客户版 Word。
- Word 附件以 OOXML `altChunk` 保存原文件字节；Excel 附件转为 Word 可导入的表格内容。
- PDF、图片和演示文稿仍保留在线预览 / 下载入口，报价 Word 中只列出附件名称，不伪造版式保真结论。

## 安全边界

- 只有研发经理、综合部经理和副总经理依次审批通过的报价快照可生成客户版 Word。
- 客户版 Word 不展示内部审批意见；审批记录仍保留在系统中。
- 生成前后均校验快照金额、快照摘要和附件 SHA-256。
